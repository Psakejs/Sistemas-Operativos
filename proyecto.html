Proyecto final

Demostración del funcionamiento del sistema operativo mediante una explicación técnica y una actividad práctica.

Propósito

Instalar Lubuntu junto a Windows en mi portátil, con arranque dual, para aprender los fundamentos de Linux y usar el equipo como un laboratorio en casa. El proyecto muestra en la práctica cómo arranca un computador, cómo se organiza el disco y cómo el sistema operativo administra los recursos.

Resultado: el arranque dual funciona. GRUB muestra Lubuntu y Windows Boot Manager, los dos sistemas arrancan, y Lubuntu quedó actualizado y probado.

Equipo y sistema

  • Portátil: Lenovo IdeaPad S145-14IWL (81MU).
  • Procesador: Intel Core i7-8565U, 4 núcleos y 8 hilos.
  • Memoria: 4 GB de RAM.
  • Gráficos: Intel UHD Graphics 620 y NVIDIA GeForce MX110 de 2 GB.
  • Almacenamiento: disco duro WD de 1 TB, 2,5 pulgadas, 5400 RPM (SMR).
  • Red inalámbrica: Qualcomm Atheros QCA9377.
  • Firmware: UEFI, Lenovo ASCN37WW (2019-07-04).
  • Sistema original: Windows 10 Pro.
  • Sistema instalado: Lubuntu 26.04.1 LTS con escritorio LXQt 2.3.2 (kernel registrado: 7.0.0-43-generic).

Se eligió Lubuntu porque su escritorio LXQt es liviano y funciona bien con 4 GB de RAM.

Desarrollo del proyecto

  • Identificación del entorno: se revisaron el hardware del portátil, el firmware UEFI y el estado del disco antes de cambiar nada.
  • Exploración del sistema: con inxi, lsblk, uname -a y hostnamectl se consultaron el procesador, la memoria, los discos y el kernel.
  • Administración de recursos: se instalaron htop (procesos, CPU y RAM), iotop (uso del disco por proceso), sysstat (estadísticas como iostat), lm-sensors (temperaturas) y smartmontools (salud del disco con smartctl).
  • Configuración o solución: particionado manual del disco y configuración del arranque dual con GRUB, sin tocar las particiones de Windows.
  • Análisis: se explica qué hace el sistema operativo en cada etapa del arranque y cómo se comprobó que todo funciona.

Procedimiento paso a paso

  1. Respaldo: como el disco tiene errores de lectura y sectores pendientes, los archivos importantes se copiaron (no se movieron) y se verificaron las copias.
  2. Espacio: se redujo la unidad D: en unos 102.400 MB para dejarle unos 100 GB a Lubuntu.
  3. USB de instalación: se grabó la ISO de Lubuntu con Rufus, con esquema GPT para arranque UEFI (no BIOS/CSM).
  4. Arranque desde el USB: como F12 no abría bien el menú de Lenovo, se usó Inicio avanzado de Windows → Usar un dispositivo.
  5. Sesión en vivo: antes de instalar se probaron el Wi-Fi y el audio desde el USB.
  6. Particionado manual: se usó solo el espacio libre y se crearon dos particiones: EFI y raíz.
  7. Arranque dual: se comprobó que GRUB muestra Lubuntu y Windows Boot Manager, y que los dos arrancan.
  8. Primer inicio: se ejecutaron sudo apt update y sudo apt upgrade, y se probaron Wi-Fi, audio, navegador y YouTube, pantalla, teclado, touchpad, batería, suspensión y apagado.

Se usaron dos particiones porque tienen funciones distintas: la EFI guarda los archivos de arranque que lanza el firmware, y la raíz contiene el sistema, las aplicaciones, la configuración y los archivos del usuario. Linux puede compartir la partición EFI de Windows, pero se creó una aparte para mantener separados los dos sistemas.

Ojo con las unidades: los instaladores mezclan MB y MiB, y GB y GiB. Antes de aplicar los cambios se confirmaron el tamaño, el formato y el punto de montaje.

Cómo arranca el equipo

  1. UEFI inicializa el hardware y ejecuta una entrada de arranque EFI.
  2. La partición EFI guarda los archivos de arranque que el firmware puede lanzar.
  3. GRUB muestra el menú y arranca el sistema elegido.
  4. La partición raíz / se monta y Lubuntu termina de iniciar.

Si GRUB falla, el equipo no encuentra qué cargar o arranca directo a Windows. Se puede reparar desde un USB en vivo, reinstalando GRUB o revisando el orden de arranque UEFI.

Recomendaciones

  • Hacer copias de seguridad antes de reducir particiones o instalar, y comprobar que se pueden abrir.
  • No formatear ni modificar las particiones NTFS de Windows durante la instalación.
  • Crear el USB con el mismo modo del firmware: GPT para UEFI.
  • Revisar el tamaño, el formato y el punto de montaje antes de aplicar los cambios de particiones.
  • Vigilar el disco con smartctl y no guardar en él datos irremplazables.
  • No mostrar contraseñas, datos personales ni información privada durante la grabación.
