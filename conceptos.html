Conceptos

Completa los recuadros con conceptos relevantes y sus respectivas definiciones.

▣HARDWARE

Procesador (CPU): se encarga de las tareas generales del equipo. Un procesador multinúcleo solo rinde más si los programas están hechos para ejecutarse en paralelo.

Núcleo e hilo: los núcleos son unidades reales de procesamiento; los hilos son unidades lógicas que el sistema operativo planifica. Con Hyper-Threading cada núcleo físico maneja dos hilos.

Memoria RAM: memoria volátil diseñada para acceso rápido durante la ejecución; pierde su contenido cuando el equipo se apaga.

Almacenamiento permanente: SSD o disco duro: no es volátil, tiene mayor capacidad y es más lento que la RAM; guarda la información de forma permanente.

Generaciones DDR: DDR3 trabaja alrededor de 1066–1333 MHz, DDR4 de 2666 a 3200 MHz y DDR5 de 4800 a 8600 MT/s. Cada generación usa voltajes, pines y velocidades diferentes, así que la placa base debe soportarla.

Buses de transferencia: caminos por donde se mueven los datos entre el procesador, la memoria RAM y otros componentes.

MT/s: megatransferencias por segundo: cuántas transferencias de datos puede hacer el bus por segundo. Un valor más alto generalmente significa mayor ancho de banda.

Chip gráfico (GPU): componente que procesa la información visual. Los gráficos integrados vienen dentro del procesador y comparten la RAM del sistema; una tarjeta dedicada tiene su propio procesador y su propia VRAM.

Compatibilidad: la placa base debe soportar el procesador (socket y chipset), la generación de RAM y la tarjeta gráfica (ranura PCIe y conectores de poder); la fuente y la refrigeración también deben ser adecuadas.

⌘SOFTWARE

Sistema operativo: software que administra los recursos del equipo y sirve de intermediario entre el usuario, las aplicaciones y el hardware.

Kernel: parte central del sistema operativo; corre en modo privilegiado y maneja el procesador, la memoria y los dispositivos.

Controlador (driver): software que permite al kernel comunicarse con una pieza específica de hardware, como una impresora.

Llamada al sistema: mecanismo controlado con el que una aplicación en modo usuario hace peticiones al kernel; es la única forma segura de acceder a recursos protegidos.

Programa y proceso: el programa son instrucciones guardadas en el disco; el proceso es una instancia en ejecución con CPU y memoria asignadas.

Bloque de control de procesos: estructura donde el SO guarda el estado del proceso, el contador del proceso, los registros y los límites de memoria.

Planificador: decide qué proceso corre y por cuánto tiempo, con algoritmos como FCFS (orden de llegada) y SJF (primero el más corto).

Memoria virtual: cuando la RAM no alcanza, el SO mueve páginas poco usadas al archivo de paginación en el disco, que es mucho más lento.

Shell: intérprete que lee y ejecuta los comandos, como interfaz entre el usuario y el kernel; por ejemplo Bash en Linux o PowerShell en Windows.

Gestor de arranque: programa que muestra el menú de sistemas y arranca el que se elija; en el proyecto, GRUB (GNU GRand Unified Bootloader).

⌁REDES

Sistema distribuido: colección de computadores conectados por una red que coordinan sus acciones mandándose mensajes y aparecen como un único sistema coherente.

Cliente-servidor de tres niveles: el cliente hace la presentación y envía peticiones; el servidor de aplicaciones aplica la lógica del negocio; la base de datos guarda los datos de forma persistente.

Socket: punto de comunicación entre procesos identificado por la dirección IP y el puerto.

Cola de mensajes: el mensaje espera en la cola hasta que el receptor lo procesa, así el emisor sigue trabajando aunque el otro proceso esté ocupado.

Síncrona y asíncrona: en la síncrona el emisor espera la respuesta antes de continuar; en la asíncrona sigue trabajando y recibe la respuesta después.

Publicación-suscripción: modelo asíncrono para notificaciones como alertas de stock bajo o reportes diarios.

Transparencia: permite acceder a recursos en distintos servidores sin conocer su ubicación física.

Balanceador de carga: reparte las peticiones entre varios servidores y redirige el tráfico lejos de un nodo que falló.

Sistema de archivos distribuido: los archivos se replican en varios servidores y el usuario accede sin saber en cuál están.

◇SEGURIDAD

Permisos de acceso: controlan qué usuarios o procesos pueden leer, escribir, eliminar o ejecutar un archivo, protegiendo la información sensible.

Cuenta de usuario estándar: usar una cuenta estándar y no de administrador para el trabajo diario evita instalar programas sin autorización del área de soporte.

Control de acceso basado en roles: limita quién puede ver o modificar cada carpeta o archivo según el cargo de la persona.

Sección crítica: parte del código que accede a un recurso compartido y que no puede ejecutar más de un proceso a la vez.

Condición de carrera: situación en la que el resultado final depende del tiempo de las operaciones; en un banco puede producir saldos incorrectos.

Semáforo: contador entero con las operaciones espera (wait) y señal (signal). El binario (0 y 1) protege un archivo compartido; el contador permite, por ejemplo, máximo tres conexiones a una base de datos.

Bloqueo (deadlock): varios procesos esperan indefinidamente por recursos que tienen otros; se previene tomando los bloqueos siempre en el mismo orden y usando tiempos de espera.

Tolerancia a fallos: redundancia, copia de datos, conmutación por error automática y protocolos de confirmación para que el sistema siga operando y los datos queden íntegros.

Copias de seguridad: respaldo regular para restaurar la información; si el disco presenta errores, se copian los archivos en vez de moverlos y se verifican las copias.
